# 35mm F2.8 工业镜头专利筛选

检索日期：2026年10月10日。检索来源：Google Patents。

根据用户提供的需求，优先建议以 **CN110703413B 的实施例3** 作为可复建的光学设计起点，以 **CN217060609U** 作为紧凑结构备选。**CN213276098U** 的高分辨率与低畸变结构值得参考，但其公开实施例的第一面至像面距离约65.5mm，超过60mm要求。本次没有找到一件公开资料已证明满足全部指标的专利。

这里的“推荐”是对光学设计参考价值的判断，未开展光线追迹、优化、容差或量产验证，也未开展权利要求侵权比对。

后续复建更新：已按用户要求通过ZOSPy导入CN110703413B实施例3。按公开曲率、间隔和Nd/Vd模型玻璃复建，在500mm配置下有效焦距约29.86665mm，固定像面存在离焦，尚未复现标称35mm。独立近轴矩阵计算得到相同结果；因此上述首选仅指公开数值资料便于复建，不应认定该处方可直接达到需求。详见[导入与复建说明](../zemax_import/CN110703413B_example3/导入说明.md)。

## 筛选基准

需求来源：原项目提供的 35 mm F/2.8 技术需求；原始需求文档不随本仓库发布。

| 项目 | 需求 |
|---|---|
| 焦距及光圈 | 35mm，最佳物距处；F2.8 |
| 像面 | 1.1英寸，明确要求直径≥18mm |
| 物距 | 最佳0.4–0.5m，常规0.2–2m，转接环支持0.1m |
| 最佳物距分辨率 | 中心225lp/mm，边缘180lp/mm |
| 最短物距分辨率 | 中心150lp/mm，边缘120lp/mm |
| 畸变 | 最佳物距0.3%，最短物距0.6% |
| 相对照度及主光线角 | RI≥75%；CRA≤10°，无穷远处 |
| 长度及后焦 | 最大光学总长≤60mm；后焦≥8mm |
| 调焦及口径 | 分组调焦，行程约6mm；最大镜片≤23mm |
| 波段及温度 | 可见光，支持850nm；−20至+60°C |

文档没有规定上述空间频率对应的最低MTF值，专利中的“支持多少万像素”或“达到200lp/mm”不能直接等同于通过需求验收。像面按明确给出的Φ18mm筛选，不能仅凭“1.1英寸”标签判定满足。

## 首选方案的原文核对

CN110703413B，原始PDF第8页（说明书6/7页）表7提供实施例3的各面参数，第9页（说明书7/7页）表8明确列出35mm、F2.8、TTL50mm。表7标题误写为“实施例2”，但它位于“实施例3”段落内，并接续表8，应按上下文识别。

表7提供曲率、各面之后的厚度或空气间隔、Nd与Vd。最后一行L8R2后的间隔为14.65mm，可以作为该实施例的末面至像面后焦参考。实际玻璃牌号未明确，需要进一步匹配玻璃目录；只匹配Nd与Vd不能证明850nm性能。

表9列出的前后调焦组间隔为：

| 物距 | 150mm | 300mm | 500mm | 1000mm | 无穷远 |
|---|---:|---:|---:|---:|---:|
| L6与L7间隔 | 7.71mm | 4.88mm | 3.13mm | 1.88mm | 0.79mm |

这些是组间空气间隔，不是全部相对于同一基准的调焦行程。150mm至无穷远的间隔变化为6.92mm；200mm和2000mm没有直接列出，不能将6.92mm当成需求物距范围的准确行程。

说明书对实施例3披露：WD500mm下畸变<0.2%；−30°C与+70°C下离焦量控制在0.01mm内。它并未给出实施例3在225lp/mm处的验收数据。文中200lp/mm中心约0.45、边缘约0.35的MTF描述属于25mm/F1.82的实施例1，**不能移用到35mm的实施例3**。

以上依据：[Google Patents原文](https://patents.google.com/patent/CN110703413B/zh)，[公开PDF](https://patentimages.storage.googleapis.com/98/4a/ee/750898f8181b7a/CN110703413B.pdf)。

## 后续设计应优先验证的项目

1. 按CN110703413B实施例3复建，先确认35mm、F2.8、物距500mm附近的基础成像与尺寸，再将半像高扩展到9mm。保留末组固定、前组调焦的结构作为起点。
2. 在200、400、500、800、2000mm及无穷远配置下验证像质、畸变、最大总长和调焦行程；用转接环另设100mm配置。需先统一“物距”是从镜头前端、第一面还是主平面测量。
3. 分别验证可见光、650nm和850nm。需求中的“支持850nm”没有说明换波段后是否允许重新调焦，不能自动理解成可见光与850nm必须共焦。
4. 检查225/180lp/mm及150/120lp/mm处的MTF，并补充最低对比度标准；检查RI≥75%、无穷远CRA≤10°及所有镜片的实际直径≤23mm。此次入选专利均未找到证明这三项同时满足的充分数据。

公开专利可用于研究结构与参数；本次排序不代表商业实施的自由使用结论。
